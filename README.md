# ОЧКАРИК

Хоррор-выживание от первого лица. Ты в кровати, он идёт к тебе через город.
Дожить до 6:00, не сойдя с ума и не заснув насмерть.

## Как запустить

Открой `index.html` в браузере. Сервер не нужен: скрипты обычные, без модулей,
переходы между страницами — обычные ссылки, поэтому всё работает и с `file://`.

Один файл для отправки кому-то собирается так:

```
node build.js
```

Получится `dist/ochkarik.html` — все четыре страницы, стили, скрипты и картинка внутри.
В таком виде роутер переключает страницы прямо в документе, без перезагрузки.

## Страницы

```
index.html          меню: сложность, старт, продолжить
game.html           ночь: комната, телефон, пауза, итог
achievements.html   список из 16 достижений
help.html           правила и клавиши
```

## Модули

```
js/router.js        переходы; работает и по ссылкам, и внутри собранного файла
js/storage.js       прогресс с подписью + сессия (что меню передаёт игре)
js/guard.js         сессия ночи: токен, открытие и запечатывание
js/achievements.js  16 достижений, у каждого своё правило-проверка
js/difficulty.js    три сложности и параметры каждой ночи
js/audio.js         около двадцати звуков на WebAudio, файлов нет
js/ui.js            единственный модуль, который трогает DOM комнаты
js/game.js          состояние, механики, цикл, пауза
js/pages.js         отрисовка меню и списка достижений
js/boot.js          общий запуск: делает только то, для чего есть разметка
build.js            сборка одностраничной версии
test/smoke.js       прогон логики и проверок защиты: node test/smoke.js
```

## Защита достижений

Три независимых слоя, поэтому получить награду мимо игры не выйдет:

1. **Сессия.** В начале ночи `Guard` выдаёт одноразовый токен. Выдача принимается
   только с ним и только пока ночь идёт; после финала сессия запечатывается.
2. **Страница.** Заявка проверяет, что текущая страница — `game`. Из меню, со
   страницы достижений и из консоли на другой вкладке ничего не выдаётся.
3. **Правило.** У каждого достижения есть функция от фактических итогов ночи, плюс
   отсев невозможных цифр (ночь длиннее себя самой, побегов больше, чем успевает
   случиться). Даже с токеном нельзя заявить то, чего не было.

Сохранение подписано контрольной суммой: если файл правили руками, достижения
сбрасываются, а в меню появляется об этом строка.

Честно про границы: всё это живёт в браузере, поэтому от человека, который откроет
исходники и позовёт функции в правильном порядке, оно не спасёт. Задача другая —
чтобы награда не могла упасть случайно и чтобы её нельзя было выбить кликом мимо игры.

## Управление

| Действие | Клавиша | Кнопка |
|---|---|---|
| Спать / проснуться | Пробел | «Спать», а во сне — круг посреди экрана |
| Телефон | E | «Телефон» |
| Дверь | Q | «Дверь» |
| Пауза и выход в меню | Esc | «Пауза» слева внизу |

## Что можно докрутить

- Новые сущности со своим поведением.
- Расходники: пауэрбанк на тумбочке, беруши, будильник.
- Записки между ночами.
